# Animations JS

This project shows two simple HTML files that show animations done using JavaScript, during the class of Ing. Daniel Chaires Martínez. Below I describe what each file contains.

## AnimationsJS.html
This is a file that shows five different cubes that when hovered, trigger the next animations:
* Cube 1: Changes opacity
* Cube 2: Changes color
* Cube 3: Rotates
* Cube 4: Moves on the "X" axis
* Cube 5: Grows

[File link](https://github.com/velacarrdany/AnimationsJS/blob/master/AnimationsJS.html)
